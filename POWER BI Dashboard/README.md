# 📊 Sales Performance Dashboard – Power BI

## 📁 Project Overview
The **Sales Performance Dashboard** is an interactive Power BI report built to analyze and visualize sales performance using the *Superstore* dataset.  
It provides insights into revenue, profit, quantity, customer segments, and regional trends — helping users make data-driven decisions.

---

## 🎯 Objectives
- Analyze total **Sales**, **Profit**, and **Quantity** across categories and regions.  
- Identify **top-performing products** and **key customers**.  
- Monitor **sales trends over time** (monthly and yearly).  
- Visualize **profit margins** and **discount impacts**.  

---

## 🧩 Key Features
✅ **Interactive Dashboard:** Filter by Region, Category, Segment, and Date.  
✅ **Visual Insights:** Bar charts, line charts, maps, and KPI cards.  
✅ **Trend Analysis:** Understand sales patterns over time.  
✅ **Customer Insights:** Identify top 10 customers and profitable segments.

---

## 📊 Dashboard Contents
| Visual | Description |
|--------|--------------|
| **Cards** | Total Sales, Profit, and Quantity |
| **Bar Chart** | Sales by Category and Sub-Category |
| **Line Chart** | Monthly Sales Trend |
| **Pie / Donut Chart** | Sales by Segment |

---

## 🧮 Dataset Details
**Dataset:** Superstore.csv  
**Columns Used:**  
`Order Date`, `Sales`, `Profit`, `Quantity`, `Category`, `Sub-Category`, `Region`, `State`, `Segment`, `Discount`, `Customer Name`.
